## 6.2
@ex Finding an unknown
Q: $X$ takes values $1,2,3,4$ with $P(X=x)=kx$. Find $k$ and $P(X\ge3)$.
S: $k(1+2+3+4)=1\Rightarrow k=\frac1{10}$.
S: $P(X\ge3)=\frac3{10}+\frac4{10}=\frac7{10}$.
A: $k=0.1$ and $P(X\ge3)=0.7$
@p **Two rules for any probability distribution:** every probability is between 0 and 1, and the probabilities add to exactly 1. Use the second to solve for unknowns, then check the first.
## 6.3
@ex Expected value
Q: $x=0,1,2$ with $p=0.5,0.3,0.2$. Find $E(X)$.
S: $0(0.5)+1(0.3)+2(0.2)=0.7$.
A: $0.7$
@ex Linear change
Q: $E(X)=4$. Find $E(3X-2)$.
S: $E(aX+b)=aE(X)+b=3(4)-2=10$.
A: $10$
## 6.4
@ex Variance two ways
Q: Using the table above, find $\text{Var}(X)$.
S: $E(X^2)=0(0.5)+1(0.3)+4(0.2)=1.1$.
S: $\text{Var}=1.1-0.7^2=0.61$.
A: $0.61$, so $\sigma\approx0.781$
@key **Linear change of variance:** $\text{Var}(aX+b)=a^2\text{Var}(X)$. Adding a constant does not change spread; multiplying by $a$ scales the standard deviation by $|a|$.
## 6.5
@ex Fair game
Q: Pay $\$2$ to roll a die; win $\$6$ if you roll a 6, else nothing. Expected profit?
S: $E(\text{win})=6\cdot\frac16=1$; profit $=1-2=-1$.
A: $-\$1$ per game, so it is not fair.
## X | Exam toolkit
@p **Table method.** Add a row for $xp$ and a row for $x^2p$. Sums give $E(X)$ and $E(X^2)$. This avoids arithmetic slips and shows method marks.
@p **Interpreting.** $E(X)$ is the long-run average, not a value you expect on one trial. Say "in the long run" in context. A game is fair when expected profit is zero.
